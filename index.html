How It Works

01 lock

Encrypt

Your file or text is encrypted client-side with AES-256-GCM before leaving your browser. The key never touches a server.

02 cloud_upload

Pin to IPFS

The ciphertext is pinned to IPFS via Pinata. Nobody can read it — the CID is content-addressed and immutable.

03 receipt_long

Mint RDO

A smart contract object is minted on-chain encoding the IPFS CID, access type (public/whitelist), open limit, and violation policy.

04 policy

Consume

Recipients request access. If they meet the criteria, the contract emits a signal. They decrypt and consume the content locally.

Self-Sovereign Encryption

Solving the Key Delivery Problem

Traditionally, end-to-end encrypted files face a massive delivery flaw: the creator must manually send the AES decryption password to authorized recipients via Slack or Email. Handing over the key manually entirely defeats the purpose of trustless on-chain access controls.

vpn_key

Invisible On-Chain PKI

RDO v2 implements Per-Recipient Wallet Encryption. Recipients register a free RSA Profile on the smart contract. Their private key is backed up locally, shielded by a deterministic vault derived from a secure wallet signature. When an RDO is created, the AES decryption shard is wrapped specifically for each whitelisted user natively in the browser. No manual sharing required.

gavel The Skeptic's Corner

forum Why not just use WhatsApp?

Standard messenger platforms control the key infrastructure and allow recipients to use modified clients to intercept data. RDO keys are completely self-sovereign—you interact directly with the smart contract, allowing you to execute absolute, mathematically-provable, instantaneous revocation globally that forces the file to lock down.

photo_camera Print Screens & The "Analog Hole"

"What if they just take a picture of the screen?" Disabling 'Copy' and 'Download' prevents instant digital mass-distribution and programmatic scraping. While someone can manually photograph a screen, this severely restricts the "blast radius" from immediate zero-friction viral sharing to an extremely high-friction, low-quality physical capture.

What Makes RDO Different

The Asset Stays Yours

Unlike traditional DRM, revoking access doesn't destroy or move the asset — it updates a single boolean in the contract. The encrypted payload stays on IPFS forever. Only the on-chain permission changes.

Auto-Lock on Violation

Exceed the open limit or trigger a policy breach — the contract self-locks without any creator intervention. You set the rules once.

shield_lock

Whitelist Gating

Restrict access to specific wallet addresses. Only wallets you approve can submit a valid access request — everyone else gets rejected at the contract level.
